
# VR O‘quv-trenajyor tizimi

## Loyiha mavzusi
Kompyuter laboratoriyasida xavfsizlik qoidalariga rioya qilish bo‘yicha VR o‘quv-trenajyor.

## Loyiha maqsadi
Virtual muhit orqali foydalanuvchilarga kompyuter laboratoriyasida xavfsizlik qoidalarini amaliy o‘rgatish.

## Asosiy imkoniyatlari
- 3D virtual xona.
- Interaktiv obyektlar.
- 4 ta o‘quv bosqichi.
- To‘g‘ri va noto‘g‘ri harakatlarni aniqlash.
- Xatolar sonini hisoblash.
- Vaqtni hisoblash.
- Natijalarni localStorage orqali saqlash.
- Yakuniy natijalarni ko‘rsatish.
- Mashg‘ulotni qayta boshlash.

## Foydalanilgan texnologiyalar
- HTML
- CSS
- JavaScript
- A-Frame 1.5.0
- WebXR
- localStorage

## Loyihani ishga tushirish
`index.html` faylini brauzerda oching.
